# IndiaKart E-Commerce Sales Analysis
# Project Overview
An end-to-end e-commerce sales analysis project using Python, PostgreSQL, and Power BI.

# Project Phases
1. Data Cleaning — Python / Jupyter Notebook
Cleaned missing values, duplicates, and data types.
Prepared the data for analysis.

2. Exploratory Data Analysis (EDA) — Python / Jupyter Notebook
Analyzed sales trends, categories, products, and customer patterns.

3. KPI Calculation — PostgreSQL
Calculated key metrics such as total sales, total orders, profit, and average order value.

4. Dashboard Development — Power BI
Created an interactive dashboard to present sales performance and business insights.

# Tools Used
Python
Jupyter Notebook
Pandas, NumPy, Matplotlib, Seaborn
PostgreSQL / SQL
Power BI
